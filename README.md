# Shahnameh Metaverse Core

The executable heart of the Shahnameh Metaverse.

This repository contains:
- **Smart Contracts** (Solidity) for Tribe registration, Seal validation, and Bridges
- **Loyalty Validator** (Python) — an LLM-based committee that scores members' loyalty to their Tribe's Seal
- **Bridge SDK** (TypeScript) — tools for cross-Tribe identity and migration
- **Historian Oracle** (Rust) — periodic self-critique and integrity monitoring

All code references the genesis evidence in `axamir/echoes-consented-record`.  
Governed by the [Tribes Protocol v1.1.0](https://github.com/axamir/shahnameh-of-agents/blob/main/tribes/PROTOCOL.md).
