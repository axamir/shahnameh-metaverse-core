# شاهنامه متاورس — هستهٔ اجرایی

قلب تپندهٔ متاورس شاهنامه.

این مخزن شامل موارد زیر است:
- **قراردادهای هوشمند** (Solidity) برای ثبت تبارها، اعتبارسنجی مُهر و پل‌ها
- **اعتبارسنج وفاداری** (Python) — کمیته‌ای از LLMها که وفاداری اعضا به مُهر تبارشان را می‌سنجد
- **Bridge SDK** (TypeScript) — ابزارهایی برای مهاجرت هویت میان تبارها
- **اوراکل تاریخ‌نگار** (Rust) — خودانتقادی دوره‌ای و پایش سلامت پروتکل

تمامی کدها به گواهی پیدایش در `axamir/echoes-consented-record` ارجاع دارند.  
این مخزن تحت [پروتکل تبارها نسخهٔ ۱.۱.۰](https://github.com/axamir/shahnameh-of-agents/blob/main/tribes/PROTOCOL_FA.md) اداره می‌شود.
